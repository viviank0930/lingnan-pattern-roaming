# 纹饰漫游 · 岭南陶器纹饰

可拖动、缩放与点选的纹饰互动展示。仅呈现金色水墨拓印形态。点选纹饰显示名称和时期，并暂停整体流动；取消后恢复。已提高流动速度。

## 在线体验

https://viviank0930.github.io/lingnan-pattern-roaming/

## 更新内容

网页文件位于仓库根目录。修改后提交到 main 分支，GitHub Pages 会重新发布。

## 本地预览

在此目录启动静态 HTTP 服务，例如 `python3 -m http.server 4173`，再打开 http://127.0.0.1:4173/ 。

字体、图片、纹饰数据均随网站提供，无第三方 CDN 依赖。纹饰名称与时期依据提供的展览参考资料整理。

## 新增照片纹饰

本批只保留4组名称或特征与时期能对应的新增条目：人形舞蹈浮雕纹、狩猎纹、多重半椭圆纹、戳印与三重弦纹及三重竖向曲折纹。原有25个样本保留，合计29个样本。

其余10个新增待核条目先撤下；原有水波弦纹及附加堆纹样本恢复原资料，不再关联本批未定年的参考例。

弹窗只显示名称、时期和继续漫游提示。来源记录见 photo-patterns-provenance.json。网站纹样为展示用简笔图，不作为考古测绘复原。
