# 纹饰漫游

[打开在线网站](https://viviank0930.github.io/lingnan-pattern-roaming/)

岭南陶器纹饰的互动展示。拖动浏览流动的纹样，点击查看名称、时期及对应配图；点击空白处继续漫游。支持缩放与键盘操作。

## 当前版本（2026-10-26）

- 共收录 63 项纹样，均有对应配图：39 项实物照片、24 项文献线图或拓片。
- 实物照片统一使用透明背景抠图；文献线图、拓片保留原图。
- “全部纹样”以简约表格集中展示，按标注时期从早到晚排列；跨时期条目按起始时期排列，点击条目可打开对应小窗。
- 小窗显示名称、时期和图片。8 项名称待定者显示“？”，并保留已确认文案“该纹饰在广东首次发现，名称尚未确定。”
- 按图形去重，不因同形异名重复收录；不将“附加堆纹”这类工艺名称作为固定图案展示。尚未核实名称、时期与图像对应关系的项目不收录。

资料依据包括用户提供的纹饰表、陶片综合图、《第二节 陶瓷技术》、任诗仪《岭南地区出土先秦时期印纹硬陶初探》及张倩《汉代岭南硬陶戳印纹饰的初步研究》。条目中的来源、页码、图号等保留在 patterns.json；流动图形为对应图像的展示用整理，不作为独立命名或断代依据。

## 本地运行

在本目录启动静态 HTTP 服务后打开页面，例如：

```sh
python3 -m http.server 8765
```

使用 `?motif=7001` 等参数可直接查看对应条目。网站为纯静态文件，由 GitHub Pages 发布。
